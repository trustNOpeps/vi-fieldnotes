# VI Fieldnotes — Portfolio Case Study

**Independent editorial web product · UX, front-end, research and SEO**

Primary website: https://vi-fieldnotes.pages.dev/
GitHub Pages preview: https://trustnopeps.github.io/vi-fieldnotes/
Source: https://github.com/trustNOpeps/vi-fieldnotes

## Problem and objective

GTA VI readers encounter conflicting rumors and practical launch questions about platforms, editions, regional timing and console storage. VI Fieldnotes offers a lightweight, independent source-first guide with simple preparation tools.

## Scope and delivered product

- 15 source-linked GTA VI articles and 23 discoverable website routes.
- Searchable guide library, topic filters, FAQ search with accessible empty states.
- Ten-step launch checklist with browser-local saved progress.
- Browser-only PS5 storage calculator based on first-party published guidance.
- Original abstract neon-coast SVG artwork; cream, indigo, violet, mint and coral design palette.
- Responsive navigation, accessible keyboard focus, reduced-motion behavior and privacy-friendly analytics consent.
- XML sitemap, canonical metadata, robots.txt, Cloudflare Pages root-path build, GitHub Pages preview and automated GitHub Actions quality checks.

## Technology and decisions

HTML5, CSS and vanilla JavaScript, no application backend or secret keys. The primary website uses Cloudflare Pages. GitHub holds the source and a separate Pages preview. A small Python build step rewrites the project-path links, canonical metadata, sitemap and robots.txt for root-path hosting. Original artwork and prominent non-affiliation notices avoid presenting the project as an official Rockstar product.

## Role and process

Product concept, editorial research direction, visual direction, implementation, QA and publishing with AI-assisted workflows. Factual claims use Rockstar or first-party platform documentation and dated review notes.

## Verification and boundaries

The repository has CI for static route/asset consistency, JavaScript syntax and the root-domain build. Public browser QA inspected desktop, tablet and mobile layouts, the guide and FAQ search, tools and navigation. Report outcomes separately from unmeasured metrics.

**No traffic, Search ranking, PageSpeed score, paid affiliate relationships, revenue, sponsorship or official Rockstar partnership is claimed.** First content review baseline: 14 November 2026. Time-sensitive launch facts need regular rechecking.

## Portfolio summary

VI Fieldnotes is an independent, responsive GTA VI information site combining 15 source-backed guides, original visual design, searchable content, a PS5 storage calculator and an interactive launch checklist. Built using AI-assisted research and front-end workflows with accessibility, consent-first analytics, automated QA and Cloudflare Pages publishing.

## Future improvements

Document measured Lighthouse/Core Web Vitals, upgrade Open Graph preview to a widely supported raster image, add verified user-facing results only after measurement, and refresh post-launch content. A custom domain, monetization approvals and measured commercial outcomes remain separate future steps; the current public address is a pages.dev subdomain.
